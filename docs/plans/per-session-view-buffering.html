Per-Session View & Stream Buffering

Cô lập output theo session: chỉ active session stream xuống chat; background session buffer trong RAM. Approval/question auto-switch session lên active + notify. Stream silent (no push notif) đến khi critical event xảy ra. Inline session-strip cho phép quick-switch.

Author: Telecode Project Date: 2026-05-20 Target: v0.8 Effort: ~2 ngày Status: Approved by user — executing

TL;DR

Multi-session v0.7 hiện gửi mọi stream về cùng 1 chat → user thấy log mix. Sprint này thêm per-session output gating: background session output ghi RAM buffer thay vì gửi chat; user switch sang session đó mới flush. Stream gửi xuống chat dùng Telegram disable_notification:true (im lặng, không tone). Khi background session cần approval/question → auto-switch session đó lên active + push notify. Mọi message critical (approval, done, error) kèm session strip inline button để quick-switch.

3. Architecture & shared infra

3.1 OutputBuffer (src/session/output-buffer.ts) — NEW

Per-session ring buffer trong RAM, cap mặc định 50KB. Khi vượt cap, drop chunks giữa, giữ phần đầu + cuối, chèn marker … [N chunks omitted] ….

export interface BufferedEvent {
  type: 'text' | 'tool_use' | 'status';
  data: string;       // formatted line ready to flush
  createdAt: number;
}

export class OutputBuffer {
  private events: BufferedEvent[] = [];
  private bytes = 0;
  constructor(private readonly capBytes: number = 50_000) {}

  append(event: BufferedEvent): void {
    this.events.push(event);
    this.bytes += event.data.length;
    while (this.bytes > this.capBytes && this.events.length > 4) {
      // drop from middle, keep first 2 + last 2 + marker
      const dropped = this.events.splice(2, this.events.length - 4, {
        type: 'status',
        data: `… [${this.events.length - 4} chunks omitted] …`,
        createdAt: Date.now(),
      });
      this.bytes -= dropped.reduce((s, e) => s + e.data.length, 0);
    }
  }
  drain(): BufferedEvent[] { const out = this.events; this.events = []; this.bytes = 0; return out; }
  size(): number { return this.events.length; }
  isEmpty(): boolean { return this.events.length === 0; }
}

3.5 Approval/question auto-switch (R5)

Trong router.ts:

deps.broker.attach({
  async prompt(req: ApprovalRequest) {
    // R5: auto-switch if backgrounded
    const cur = deps.store.getChatState(req.chatId).active_session_id;
    if (cur !== req.sessionId) {
      // First-come-first-active: only auto-switch if no other pending approval
      if (!deps.broker.hasPendingFor(req.chatId, cur)) {
        deps.store.setActiveSession(req.chatId, req.sessionId);
        // Flush incoming session's buffer so user sees recent context
        const buffered = deps.manager.drainBuffer(req.sessionId);
        if (buffered.length) {
          await notifier.sendPlain(catchUpHeader(req.sessionLabel, buffered));
        }
      }
    }
    // Send approval prompt + session strip + NOTIFY (default sound)
    await notifier.sendPlain(approvalText(req), {
      reply_markup: approvalKeyboard(req.id).inline_keyboard
        .concat(buildSessionStrip(sessions, activeId)),
    });
  }
});

6. Acceptance criteria

  • Background session text/tool_use ghi vào buffer, KHÔNG xuất hiện trong chat
  • Switch sang session có buffer → flush ra dạng catch-up message với header [label] 📥 catch-up:
  • Active session stream xuống chat với [label] prefix
  • Stream text/tool_use gửi với disable_notification:true (verify qua test mock bot.api)
  • Approval/question/done/error gửi với disable_notification không set (default = notify)
  • Approval cho background session → setActiveSession trước khi prompt
  • Approval prompt kèm session strip inline (verify reply_markup chứa session buttons)
  • Multi-approval thrashing prevention — chỉ first approval auto-switch, các approval sau chỉ notify
  • Buffer cap 50KB triggered → middle chunks dropped + marker
  • Debounce 3000ms configurable qua notifier.debounce_ms
  • Buffer cap configurable qua notifier.buffer_cap_bytes
  • Session strip pagination 4/page với >4 sessions
  • Switch session khi buffer empty → không spam empty catch-up message
  • Backward compat: existing 109 tests vẫn pass
  • Wizard interaction safe: nếu conversation đang active, defer auto-switch (chỉ notify)
  • Build + typecheck clean
