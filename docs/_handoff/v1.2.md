Đề xuất tính năng Telecode v1.2+

🔥 Ưu tiên cao (High Impact, phục vụ daily workflow)

• 📎 File sharing hai chiều (Upload → Agent)
• Người dùng gửi file/ảnh qua Telegram → tự động đặt vào inbox của session đang active → agent đọc được ngay.
• Hiện tại đã có attachments.ts nhưng chỉ download. Mở rộng: agent output file (ảnh, PDF, build artifact) → gửi ngược về Telegram dưới dạng document.
• Use case: gửi screenshot bug, mockup design, CSV data → agent xử lý trực tiếp.

• 🔔 Smart Notification & Quiet Hours
• Cấu hình "quiet hours" (vd 23:00–07:00): agent vẫn chạy nhưng không push notification, chỉ badge.
• Notification priority: chỉ ping khi cần approval hoặc session done, không ping mỗi tool result.
• /notify off / /notify approvals-only / /notify all.

• 📊 Cost Tracking & Budget Alert
• Đã có $0.023 trong done-summary. Mở rộng: tích lũy cost per session, per day, per project.
• /cost — xem tổng chi phí hôm nay / tuần / tháng, breakdown theo agent.
• Budget alert: set threshold (vd $5/ngày), khi gần đạt → cảnh báo, khi vượt → auto-pause sessions mới.

• 🔁 Session Templates / Quick Prompts
• Lưu prompt hay dùng: /template save "review" "Review code changes in staged files, focus on security".
• /template run review — tạo session mới với prompt đã lưu, không cần gõ lại.
• Kết hợp project: template gắn với project cụ thể.

⚡ Ưu tiên trung bình (UX improvement)

• 🗓 Scheduled Tasks (Cron-like)
• /schedule "Run tests" daily 08:00 — mỗi sáng tự tạo session chạy test suite, gửi kết quả.
• /schedule "git pull && build" on-push — webhook trigger (cần thêm tiny HTTP endpoint).
• Use case: CI cá nhân chạy trên máy dev, kết quả về Telegram.

↪ (cont. 2/2)
• 🔍 Session Search & History
• /history search "auth bug" — full-text search qua transcript các session cũ.
• /history last 7d — liệt kê sessions 7 ngày gần nhất, filter theo project/agent.
• Hiện conversation-storage.ts dùng SQLite → thêm FTS5 index là đủ.

• 📌 Pinned Context / System Prompt per Project
• Mỗi project có file .telecode/context.md — nội dung tự động inject vào đầu mỗi session mới.
• Chứa coding conventions, architecture notes, "always use pnpm", "never modify prod DB".
• /context edit — sửa trực tiếp qua Telegram (gửi text → ghi file).

🌱 Ưu tiên thấp (Nice-to-have, differentiator)

• 🎙 Voice-to-Prompt
• Telegram voice message → speech-to-text (Whisper API hoặc local) → prompt cho agent.
• Tiện khi đang di chuyển, không muốn gõ.

• 📈 Session Replay / Timeline View
• Web UI nhỏ (localhost) hiển thị timeline visual: tool calls, file edits, approvals, cost — dạng Gantt.
• Link từ Telegram: 🔗 View timeline.

• 🔀 Agent Collaboration (Chain)
• Pipe output session A → input session B: Claude analyze code → output → Codex write tests based on analysis.
• /chain "Claude: analyze auth module" → "Kiro: refactor based on analysis".

• 🧪 Auto-verify Mode
• Sau khi agent done, tự động chạy npm test / cargo test / build command.
• Nếu fail → tự tạo follow-up session: "Tests failed: [error]. Fix it."
• Loop tối đa N lần (configurable), báo kết quả cuối.
